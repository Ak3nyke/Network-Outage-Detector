# Network-Outage-Detector
A clean and modern Network outage detector.

I **highly** recommend to **read** the _INSTRUCTIONS.txt_ available in the zip file since this software is still in **beta** and needs more work to make it more user friendly.

### What is the purpose of this software? 
- Since i've got an unstable internet connection, i wanted a lightweight software that works in backgroud 24/7, for when i'm outside or sleeping, in order to tell me exactly when and for how much time my connection crashed, from micro crashes (some seconds - minutes) to full crashes (hours).

### Main functions:

> You can decide what to ping (a site or a IP address) and how many seconds passes from a ping and another (in seconds).

> NOD, as soon as the connection goes in timeout, will save inside in the outage logs when the timeout happened and for how long it lasted.

> NOD has a live output and uptime functions; the live output, once reached the end of the box, will clear the oldest output, making NOD extremly lightweight

> NOD will send a notification on Windows when the connection timed out and when it started again.
